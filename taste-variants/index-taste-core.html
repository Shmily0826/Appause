In the app

What it does

01

Cooldown groups.

Bundle the apps you want to use less of, like "Short video" or "Social media". Each group gets its own 1 to 60 second cooldown before the app opens.

02

Recommended groups.

Mark apps you actually want to open more often, like a learning app. Those show up as alternatives during the cooldown, never blocked.

03

One-tap reason prompt.

While the timer runs, pick a reason: work, bored, check messages, other. The choice is logged. It does not let you skip the cooldown.

04

This week and all time.

Weekly bar chart, donut, top apps and reason breakdown. Free shows 7 days; Pro shows the full history with export.

What Appause does not do

The Accessibility service reads only the foreground app's package name. The flag canRetrieveWindowContent is set to false in the config, so Appause never sees content inside other apps. The Permission Usage Stats grant exists only to confirm an app is genuinely on top, so a media notification in the shade does not trigger a false pause.

  • No analytics SDK and no crash reporter
  • No account, no cloud sync, no remote config
  • Internet is used exactly once, on Pro activation
  • Feedback goes through system email or GitHub only
  • Source is MIT licensed on GitHub
  • Each release ships with a debug build for review
