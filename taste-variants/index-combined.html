Inside the app

Four things it does

01

Cooldown groups.

Bundle apps like "Short video" or "Social media". Each group gets a 1 to 60 second cooldown before the app actually opens.

02

Recommended groups.

Mark apps you actually want to open more often. They appear as alternatives during the cooldown, never blocked themselves.

03

One-tap reason prompt.

While the timer runs, pick: work, bored, check messages, other. The choice is logged. It does not let you skip the cooldown.

04

This week and all time.

Weekly bar chart, donut, top apps and reason breakdown. Free shows 7 days, Pro shows the full history.

Activation is offline. License tokens are signed server-side, bound to your device, and importable after a reset.

What Appause does not do

The Accessibility service reads only the foreground app's package name. The flag canRetrieveWindowContent is false in the config, so Appause never sees content inside other apps. The Usage Stats grant exists only to confirm an app is genuinely on top, so a media notification in the shade does not trigger a false pause.

  • No analytics SDK, no crash reporter
  • No account, no cloud sync, no remote config
  • Internet used exactly once, on Pro activation
  • Feedback goes through system email or GitHub
  • Source is MIT licensed on GitHub
  • Each release ships a debug build for review
