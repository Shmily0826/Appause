Set up in three steps

Download the APK from GitHub or the Lanzou mirror, then follow the install prompts.

  1. Download and allow the install

    Tap a download button, open the APK, then follow Android's install prompts.

  2. Open Appause and turn on permissions

    Follow the home screen prompts to set up permissions and background settings. See the next section for details.

  3. Create a group

    Pick the apps you want a cooldown on and set its length. Interception starts working from here.

To update later, install the new APK over the old one. Do not uninstall first: uninstalling deletes your groups and statistics. Full steps are in the install guide.

Which permissions to turn on

Follow the home screen prompts, including battery and background settings.

Required

Accessibility service
Identifies the current app and shows the pause screen. It does not read screen text or chats. Pausing needs this permission.

Recommended for reliable operation

Battery optimization set to Unrestricted
Choose Unrestricted or No restrictions to reduce interruptions from battery-saving settings.
Autostart
If your phone has this switch, turn it on to help Appause keep working after a restart or background cleanup.
Usage access
Recommended to confirm the current app and reduce unwanted pauses when switching apps.

When needed

Display over other apps
Not needed day to day. Turn it on as a fallback only if your phone does not show the pause screen.
Notifications

Your record

Each time a pause ends, Appause notes whether you continued or cancelled, for you to look back on.

Completed
After the cooldown, tap Continue to enter the app. This counts as one completion.
Avoided
You tapped Cancel on the pause screen and went home.
Reasons
The reason you picked when continuing is saved too. The free version keeps 365 days of history.
Temporary Pass
After the cooldown, choose a Temporary Pass for the current app for 5, 15 or 30 minutes. Pauses resume when it expires. This option is shown by default and can be hidden in Settings.

Questions

Still have a question? Email rng2018520@gmail.com or ask on GitHub.

How do I download it? Is there a password?

Download APK gets the file directly from GitHub. If you use the Lanzou mirror, enter password 1234.

What if Android blocks installation from this source?

Open the prompted setting, allow installs from the browser or file manager you used, then return to the installer. If Android reports a specific security risk, stop and send the warning screenshot to the developer.

Appause is greyed out in Accessibility and says "Restricted setting". What now?

On Android 13 and later, apps installed from a browser or file manager cannot turn on accessibility straight away. Tap Appause in Accessibility settings once and dismiss the message, then open Settings → Apps → Appause, tap ⋮ in the top-right corner and choose "Allow restricted settings". Confirm with your screen lock if asked, then go back to Accessibility and turn Appause on. Menu names vary by brand.

What can the accessibility service see? Why is it required?

It identifies the current app and shows the pause screen without reading screen text or chats. Pausing cannot work without it.

Does it drain the battery? Why does interception sometimes stop?

Battery use has not been measured systematically yet. If pauses stop, check the accessibility service, Unrestricted battery setting and Autostart. If the problem remains, contact the developer through Settings → Feedback.

Can other apps cover the pause screen?

The pause screen uses a higher window layer that sits above ordinary apps, and in testing it stayed visible even over apps that hide overlays. If your phone still does not show it, turn on Display over other apps and Appause will use a fallback.

Why did a pause appear for an app I did not open?

On some phones, opening Recents, switching apps or a media notification produces a system event that looks like an app switch, and a pause can appear by mistake. Turning on Usage access makes this rarer, but cannot rule it out.

Does Pro cost money? How do I get a lifetime code?

No. Start the 7-day trial on the Pro screen; each device gets one. After the trial ends, request a lifetime code through Settings → Feedback. The developer issues it by hand, and you redeem it on the Pro screen. One code works on up to 3 devices.

How do I update? What happens when I switch phones?

Install the new APK over the old one. Do not uninstall first, because that deletes your groups and statistics. There is no cloud sync and no export, so you set up groups again on a new phone.

On your new phone, start the 7-day trial on the Pro screen and wait for it to end before redeeming a lifetime code. Your existing code can be used on up to 3 devices. If a device slot is available, you can reuse it; if you reach the device limit, contact the developer through Settings → Feedback.
