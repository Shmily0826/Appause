> 新西兰持牌移民顾问和会计师确认。本文件只讨论产品与技术路线，不构成法律、
> 移民或税务意见。在取得专业意见前，暂不采用自行经营的 Stripe NZ 路线。
> 国内用户改走 **爱发电（Afdian）售卖「Pro 永久激活码」**，用户付款后爱发电自动发放卡密，
> 用户在 App 内「输入激活码」联网激活。整条链路**复用已有的 Worker + App 激活 UI**，无需改代码。

---

## 1. 流程

```
用户在爱发电付款
      │
      ▼
爱发电自动发放 卡密（APPAUSE-XXXX-XXXX）   ← 卡密来自 codes.txt
      │
      ▼
用户在 App：「设置 → Appause Pro → 输入激活码」
      │  POST {code, device} 到 Worker /api/redeem
      ▼
Worker 校验码有效 → 用私钥签一个「设备绑定」JWT 返回
      │
      ▼
App 本地用内嵌公钥验签 → 解锁 Pro（离线生效，之后不再联网）
```

- 激活是一次性的联网请求；日常使用完全离线。
- 一个激活码最多绑 **3 台设备**（Worker `DEFAULT_MAX_DEVICES=3`，可改）。
- 激活码为**买断、不过期**（`expiresInDays=null`）。

## 4. 注意事项 / 坑

- **码和 KV 必须同源**：上传到爱发电的卡密，必须和种进 KV 的是**同一份** `codes.txt`，
  否则用户买的码在 Worker 里查不到 → 激活失败（`invalid_code`）。
- **KV 是消耗品**：一个码被 redeem 后，Worker 把它标记为 `active` 并绑设备；别把同一批码重复上传到爱发电多次（会超卖）。
- **私钥只在 Cloudflare**：激活码本身不含签名，`/api/redeem` 才用私钥签 JWT。所以卡密泄露只是「白嫖一个码」，无法伪造无限码（设备上限 3 台兜底）。
- **退款**：爱发电卡密一经发货通常不支持退款；页面文案已提示「先装免费版试用」。
- **不要重跑 `genkeys`**：会换密钥、作废已发出的所有激活令牌。

## 5. 备选：纯离线激活码（不依赖 Worker）

若将来想完全去掉联网激活（例如国内访问 Cloudflare 不稳），可改为「卡密 = 一段已签名的 JWT」，
用户粘贴进 App 的「导入许可证」直接本地验签解锁。这需要持有私钥离线签批，
目前私钥只在 Cloudflare 秘钥里，故暂走上面的在线 redeem 路线。
