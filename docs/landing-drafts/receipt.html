05请自行办理的手续

不是钱的事，是权限的事。前两项办不好，东西拿回去也不灵。

  1. 无障碍服务必需

    用它识别当前前台是哪个应用，这是 Appause 唯一的核心权限，关掉即停工。

  2. 电池设为「无限制」小米 / HyperOS 必需

    不办的话系统会在后台杀掉检测服务，表现是第一次打开不拦。路径：系统设置 → 应用 → Appause → 省电策略 → 无限制。顺手允许自启动。

  3. 使用情况访问可选

    在本机二次确认真正的前台应用，减少误触发。

  4. 显示在其他应用上层可选兜底

    只有你的机器显示不出停顿屏时才开，走兼容后备方案。

08退换货须知 · 常见问题

它会看到我屏幕上的内容吗？

不会。无障碍服务只读取前台应用的包名一个字符串，canRetrieveWindowContent 设为 false，屏幕内容、消息、截图、键盘输入一概拿不到。代码 MIT 开源，可以自己查。

装了为什么不拦？

八成是电池限制。到系统设置 → 应用 → Appause → 省电策略 → 无限制，再把无障碍关掉重开一次。小米 / HyperOS 上这一步不做，服务会被系统杀掉。

能拿来管孩子或员工吗？

不能。这是给使用者本人的自我管理工具，没有远程管理能力，也不向任何人上报。权限按无障碍辅助功能如实描述。

试用到期后，正在用的会失效吗？

已有分组继续拦截，冷却和统计照常，数据不删。失效的是再次提醒、新建分组，以及自定义文案的编辑。

换手机怎么办？

数据不云同步，需要在新机器上重建分组。Pro 在新设备上重新输入同一个激活码即可，一个码最多绑 3 台。
