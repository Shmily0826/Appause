方案风格与适用场景
zh-a · 中文 / 清爽留白
浅色、多留白、功能卡片		 克制、可信的产品介绍风。适合酷安/微信文章等需要"认真读完"的渠道，以及作为默认官网首页。
zh-b · 中文 / 深色营销
暗色 hero、渐变标题、数据带		 冲击力强、转化导向。适合短视频简介、社区开屏贴、需要一眼抓住注意力的场景。
en-a · English / Minimal light
Split hero、浅色 ribbon、编辑风		 Calm, editorial tone. Suits the GitHub Pages front page and tech audiences who read before they trust.
en-b · English / Bold dark
Dark hero, gradient claims, "Zero. Zero. Zero."		 High-contrast launch/post style. Good for Reddit/X/HN launches and release announcements.
