01 / 概览

打开之前，
先停一下。

你为自己挑几个应用，设定一段等待时间。它们来到前台时，Appause 盖上一张带倒计时的停顿卡片； 时间走完，继续还是回桌面，由你决定。它不评价你看了多久，只在自动发生的动作里插进一次看得见的停顿。

02 / 工作方式

规则由你设，停顿由它执行。

  1. 建一个分组，挑几个应用

    短视频、论坛、购物，你自己选。免费版 1 个分组，Pro 不限组数。

  2. 给这一组设一段等待时间

    默认 10 秒，可在 1 到 60 秒之间调整。同一分组共用这段冷却。

  3. 应用打开，卡片盖上来

    倒计时结束前「继续」不可用；按「取消」直接回桌面。回到桌面或离开得够久，冷却重新计起。

停顿卡片的实现

它用的是系统无障碍窗口类型，不依赖「显示在其他应用上层」权限。也正因如此，在会隐藏普通悬浮层的应用上仍然盖得住。

04 / 权限与隐私

每一项权限做什么，写清楚。

只有第一项是必需的，其余要么可选，要么只在特定机型上才需要。

权限清单
权限状态用途
无障碍服务 必需 识别当前前台应用的包名，用来判断要不要拦一下。配置为 canRetrieveWindowContent = false，不读取屏幕内容、消息、截图或键盘输入。
电池不受限制 国产 ROM 必需 防止系统在后台杀掉检测服务。在小米 / HyperOS 这类机型上必须设为「无限制」，否则会出现第一次打开不拦、切回 Appause 才拦。同时建议允许自启动。
使用情况访问 可选 在本机二次确认真正的前台应用，减少通知等造成的误触发。核心判定走的是无障碍事件，不开也能拦。
显示在其他应用上层 可选兜底 正常用不到。只有你的设备确实不显示停顿卡片时才授予，让 Appause 退回兼容方案。
通知 可选 Android 13 以上可能被询问，只用于常驻运行状态通知，不参与前台应用识别。
联网 仅主动操作 只有你主动开启试用、兑换激活码或发送反馈时才会联网。日常拦截、倒计时与统计全程离线。
数据在哪里

分组、等待时间和统计记录都存在这台手机的本地数据库与偏好存储里。没有账号，没有云同步，没有分析 SDK，卸载即消失。

06 / 免费与 Pro

核心免费，Pro 是可选的实验层。

免费

永久免费 · 所有人

  • 1 个分组，把要管的应用放进去统一等待
  • 等待时间 1 至 60 秒自己定
  • 倒计时结束后继续，或随时回桌面
  • 最近 365 天的本地统计与打开原因
  • 停顿卡片上的推荐应用入口

Pro 实验功能

同样不收费

  • 不限数量的分组，工作和娱乐分开管
  • 停留在应用期间再次提醒
  • 停顿卡片上那句话可以自己写
  • 「打开原因」的选项自己定义
试用与激活的顺序

每台设备可以自愿开启一次 7 天试用，按钮在应用里，不默认开始。试用期内不能输入永久码，需要等这 7 天走完。 之后可在「设置 → 反馈」申请免费永久码，由开发者一对一发放，一个码最多绑定 3 台设备。到期不删数据，已有分组照常拦截。

免费版的等待、冷却上限（60 秒）与 365 天统计，和 Pro 完全一致。

07 / 安装

三步，第三步最容易漏。

  1. 下载 APK 并安装

    从 GitHub Releases 取签名好的安装包。手机上会提示「未知来源」，允许这一次即可。

  2. 授予无障碍服务

    在「设置 → 无障碍」里找到 Appause 并启用。这是唯一必需的一项。

  3. 把电池限制改成「无限制」

    在应用信息页里把省电策略改成「无限制」，同时允许自启动。不做这一步，系统会在后台收走检测服务。

小米 / HyperOS 用户注意

第三步不做，表现就是「第一次打开不拦、切回 Appause 才拦」。从 v0.5.29 起，这项没设好时 Appause 首页会常驻一条红色提示提醒你。 更细的步骤见 安装指南。

08 / 常见疑问

你大概想问这些。

它会看到我在应用里做什么吗？

不会。无障碍服务只读取前台应用的包名，一个字符串。它拿不到屏幕内容、消息、截图或键盘输入，配置里 canRetrieveWindowContent 设为 false。分组和记录都留在本机。

装了为什么不拦？

八成是电池限制。到系统设置 → 应用 → Appause → 省电策略 → 无限制，再把无障碍关掉重开一次。小米 / HyperOS 上这一步不做，服务会被系统杀掉。

能拿来管孩子或员工吗？

它面向使用者本人，用来执行你自己定下的规则。没有远程管理能力，不向任何人上报，也不适合监控别人的设备。

试用到期后，正在用的会失效吗？

已有分组继续拦截，冷却和统计照常，数据不删。失效的是再次提醒、新建分组，以及编辑自定义文案。

换手机怎么办？

数据不云同步，需要在新机器上重建分组。Pro 在新设备上重新输入同一个激活码即可，一个码最多绑 3 台。

能绕过它吗？

能。它可以被关掉，也可以被卸载。它是给愿意给自己设一道坎的人用的工具。
