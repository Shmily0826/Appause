## 2. 应用简介（详细描述，直接粘贴）

Appause 是一款**本地优先的专注力辅助工具**。它借助 Android 无障碍功能，在你打开容易分心的 App（如短视频、社交）之前，弹出一个简洁的「暂停屏」——给你一个冷静的窗口，决定要不要继续使用。

它**不是**封锁软件，也**不**监控你在做什么。它只是在你即将分心时，轻轻提醒你一声。

**核心功能**
- **应用分组**：把易分心的 App 归到一组，统一设置冷静时长。
- **暂停屏**：设定好分组后，打开目标 App 即弹出冷静倒计时，倒计时结束才能继续。
- **再次提醒（Pro）**：如果还在分心，可按设定时间再次轻推你一下（Appause Pro 功能）。
- **使用统计**：看清时间都花在了哪些 App 上。
- **深色模式**：跟随系统或手动切换。
- **推荐清单**：一键把常见分心 App 加进分组。
- **应用内反馈**：发现问题或想提建议，直接在设置里反馈（邮件或 GitHub Issue）。

**首次使用与运行权限**
- **无障碍服务**：识别你打开了哪个 App，决定是否弹出暂停屏。
- **电池优化设为无限制**：避免系统停止后台服务。
- **使用情况访问**：可选但建议开启，用于提高前台应用判断准确度。
- **显示悬浮窗**：可选的兼容性备用权限；通常无需开启，暂停页不显示时再尝试。

**隐私承诺（重要）**
- 全程**本地运行**：无账号、无云同步、无行为埋点、无广告。
- 无障碍服务**仅用于读取前台应用的包名**来判断是否触发暂停屏，**不读取屏幕内容、不收集任何个人信息**。
- 可选的悬浮窗权限**只用于绘制 Appause 自己的暂停屏**，不读取、不记录下层任何内容。
- 你的所有配置（分组、冷却、统计）只保存在你自己的设备上。
- 仅在你主动兑换 Pro（可选）时联网；激活码可能带有有效期，应用在本地校验令牌且不会自动联网刷新。令牌过期后可能需要再次主动兑换或导入有效令牌。该过程仅传输兑换码和设备指纹，服务端不存储任何身份或行为数据。

Appause 是开源项目（MIT 许可证），代码完全公开，欢迎查看与反馈。

## 3. 隐私与安全说明（酷安审核常问，单独填一栏）

本应用通过 Android 无障碍服务（AccessibilityService）检测当前前台应用的**包名**，用于触发「暂停屏」提醒；暂停屏通常通过无障碍覆盖层显示，不需要悬浮窗权限。SYSTEM_ALERT_WINDOW 仅作为兼容性备用，用于绘制本应用自身界面。我们**不获取屏幕内容、不录音、不截图，也不会自动上传使用数据**。分组、冷却和统计仅存储于设备本地（Room 数据库 + DataStore）。应用无后台账号体系，无第三方分析/广告 SDK。联网仅用于 Pro 激活以及用户主动发送的反馈；反馈内容和诊断信息会在发送前展示。详情见项目隐私政策：https://shmily0826.github.io/Appause/privacy-policy.html（或仓库 PRIVACY.md）。
