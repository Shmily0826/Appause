## 2. 应用简介（详细描述，直接粘贴）

Appause 是一款**本地优先的专注力辅助工具**。它借助 Android 无障碍功能，在你打开容易分心的 App（如短视频、社交）之前，弹出一个简洁的「暂停屏」——给你一个冷静的窗口，决定要不要继续使用。

它**不是**封锁软件，也**不**监控你在做什么。它只是在你即将分心时，轻轻提醒你一声。

**核心功能**
- **应用分组**：把易分心的 App 归到一组，统一设置冷静时长。
- **暂停屏**：设定好分组后，打开目标 App 即弹出冷静倒计时，倒计时结束才能继续。
- **再次提醒（Pro）**：如果还在分心，可按设定时间再次轻推你一下（Appause Pro 功能）。
- **使用统计**：看清时间都花在了哪些 App 上。
- **深色模式**：跟随系统或手动切换。
- **推荐清单**：一键把常见分心 App 加进分组。
- **应用内反馈**：发现问题或想提建议，直接在设置里反馈（邮件或 GitHub Issue）。

**隐私承诺（重要）**
- 全程**本地运行**：无账号、无云同步、无行为埋点、无广告。
- 无障碍服务**仅用于读取前台应用的包名**来判断是否触发暂停屏，**不读取屏幕内容、不收集任何个人信息**。
- 你的所有配置（分组、冷却、统计）只保存在你自己的设备上。
- 仅在开通 Pro（可选）时，会做一次**一次性联网激活**用于授权校验；该过程仅传输设备指纹，服务端不存储任何身份或行为数据。

Appause 是开源项目（MIT 许可证），代码完全公开，欢迎查看与反馈。

## 3. 隐私与安全说明（酷安审核常问，单独填一栏）

本应用通过 Android 无障碍服务（AccessibilityService）检测当前前台应用的**包名**，用于触发「暂停屏」提醒。我们**不获取屏幕内容、不录音、不截图、不上传任何个人数据**。所有使用数据均仅存储于设备本地（Room 数据库 + DataStore）。应用无后台账号体系，无第三方分析/广告 SDK。仅在用户主动开通 Pro 时进行一次联网激活校验，且仅传输设备指纹用于授权，服务端不留存身份或行为信息。详情见项目隐私政策：https://shmily0826.github.io/Appause/privacy-policy.html（或仓库 PRIVACY.md）。

## 5. 版本更新说明（v0.3.10，粘贴到「更新内容」）

- **重定义 Pro**：Pro = 无限分组 + 再次提醒 + 自定义暂停提示语。
- **免费放开更多**：更长冷却（最长 60 秒）、完整使用统计历史（365 天）现已所有人免费可用。
- 服务层按 Pro 状态真正管控「再次提醒」，免费用户即便之前开过也不会再弹出。
- 新增「设置 → 反馈」：可一键提交问题反馈或功能建议（邮件或 GitHub Issue），自动附带版本/机型信息。
- 接入 Cloudflare Worker 一次性 Pro 激活（设备绑定授权，防止开源 fork 被白嫖）。
- 修复输入框光标自动左移的问题。
